1. 기기 안에서 처리하는 자료

작업 이름·공간·일정·완료 및 취소 이력, 제품 정보·구매 메모·등록된 여분 수량·살 것 목록, 사용자가 선택한 사진 사본과 설정을 일정·재고 관리 기능을 제공하기 위해 기기에 저장합니다. 자체 계정이나 서버, 클라우드 동기화 기능은 없습니다. 작업·사진·생활 기록을 자동 송신하는 기능을 제공하지 않습니다. 실제 청소·교체 여부나 건강·안전을 판정하지 않습니다.

2. Google Play 구매 처리

일회성 Pro 구매·구매 복원·소유권 확인은 Google Play를 통해 처리되며 인터넷 연결이 필요합니다. Google Play는 자신의 정책에 따라 계정·결제·거래 관련 정보를 처리합니다. 앱은 구매 상품·구매 토큰과 확인된 권한 상태를 기기에 별도 저장하여 권한 확인과 승인 재시도에 사용합니다. 이 구매 캐시는 생활 자료 DB 및 수동 백업과 분리되며, 앱이 카드 번호나 결제 비밀번호를 입력받거나 저장하지 않습니다. Google Play와 결제 SDK를 통한 정보 처리는 Google의 개인정보처리방침(https://policies.google.com/privacy)과 Google Play 약관(https://play.google.com/about/play-terms/)도 적용됩니다.

Google Play 결제 SDK에는 결제 연결·응답·오류에 관한 진단 정보와 앱·SDK 버전, 기기 모델·운영체제·언어·국가 설정·네트워크 유형 등의 기술 정보를 Google로 전송하는 기능이 포함되어 있습니다. 앱 시작 시 결제 연결을 초기화하므로 구매를 선택하기 전에도 진단 전송이 발생할 수 있습니다. 이 앱은 해당 SDK 진단 전송을 끄는 별도 설정을 제공하지 않습니다. 진단 정보는 생활 기록과 구분되며, Google의 정보 처리에는 위 개인정보처리방침이 적용됩니다.

3. 사용자가 선택하는 외부 연결

사진 선택, 백업 저장·복구는 사용자가 고른 Android 파일·사진 제공자를 통해 이루어집니다. 클라우드 제공자를 고르면 해당 제공자의 정책에 따라 파일이 전송·보관될 수 있습니다. 구매 메모 링크는 사용자가 눌렀을 때 외부 브라우저로 열립니다. 이메일 문의는 사용자가 메일 앱에서 내용을 작성하고 직접 발송하며 앱이 기록·사진·로그를 자동 첨부하거나 자동 발송하지 않습니다. 주소 복사는 기기의 클립보드를 사용합니다.

4. 보유와 삭제

생활 자료는 사용자가 보관하는 동안 기기에 남으며 항목·제품 영구 삭제 또는 설정의 집안 데이터 전체 삭제로 지울 수 있습니다. 보관함으로 옮기는 것은 영구 삭제가 아닙니다. 삭제 정리가 끝나지 않았다는 안내가 있으면 정리 재시도를 완료해 주세요. 앱 삭제로 기기 안의 앱 자료와 구매 캐시는 제거되지만 Google Play의 구매 내역 자체가 취소되지는 않습니다. 구매 관련 보유·삭제와 환불은 Google Play의 정책을 따릅니다.

앱의 집안 데이터 전체 삭제는 Google에 이미 전송된 SDK 진단 정보의 삭제를 요청하는 기능이 아닙니다. Google이 처리하는 자료의 보유·삭제는 Google의 정책과 관련 요청 절차를 따릅니다.

5. 백업과 복구 한계

자동 OS 백업에서 앱 자료를 제외하며 수동 백업은 사용자가 선택한 저장 위치에 만듭니다. 수동 백업 파일은 암호화되지 않습니다. 외부에 저장·공유한 백업은 앱의 전체 삭제로 회수하거나 지울 수 없습니다. 외부 사본은 해당 위치에서 직접 삭제해 주세요. 구매 권한·OS 알림 권한·기기 발송 이력은 생활 자료 백업에 포함하지 않습니다. 앱 삭제·기기 분실 뒤 수동 백업이 없으면 생활 자료를 복구할 수 없습니다. 백업 파일은 작업·사진을 담고 있으므로 신뢰하는 저장 위치와 공유 대상을 선택해 주세요.

6. 문의와 변경 안내

자료 처리에 관한 문의는 위 문의 주소로 직접 보내 주세요. 방침 변경 시 앱 내 본문과 공개 정책의 시행일 및 내용을 함께 갱신합니다.
